# Dual-Panel Activity & Transport-Layer Protocol Visualizer

## Assignment 2 – Computer Networks

This project is an extension of Assignment 1, the Application Layer Protocol Visualizer.

The dashboard demonstrates how common application activities such as web browsing, email and streaming use application-layer protocols together with the TCP Transport Layer.

---

## 1. Project Overview

The project provides a dual-panel interactive dashboard.

### Left Panel – Activity Panel

The left panel allows the user to select and start different activities:

- Browsing
- Mail
- Streaming

Each activity has its own input and control.

### Right Panel – Protocol Visualization Panel

The right panel displays the protocol sequence generated by the selected activity.

It contains two synchronized views:

- Application Layer
- Transport Layer

The user can switch between the two layers using the layer tabs.

---

## 2. Application Layer

The Application Layer visualization demonstrates:

### Browsing

The browsing activity simulates:

1. DNS Query
2. DNS Response
3. HTTP Request
4. HTTP Response

### Mail

The mail activity simulates:

1. DNS lookup
2. SMTP communication
3. Email data transfer
4. SMTP response

### Streaming

The streaming activity simulates:

1. DNS resolution
2. HTTP manifest/playlist request
3. HTTP manifest/playlist response
4. Media segment requests
5. Media segment data

---

## 3. Transport Layer

The Transport Layer visualization demonstrates TCP communication for the application activities.

The visualization includes:

- TCP three-way handshake
- Data transfer
- Sequence numbers
- Acknowledgement numbers
- Window size
- TCP flags
- Data length
- Flow control
- Congestion control
- TCP connection teardown
