# AI Usage Log

## Project

Dual-Panel Activity & Transport-Layer Protocol Visualizer

## AI Tool Used

ChatGPT

## Purpose

AI assistance was used during development, debugging, UI improvement, TCP simulation design, testing guidance and documentation.

## Major Uses of AI

1. Extended the Assignment 1 Application Layer dashboard with a Transport Layer view.

2. Added a TCP three-way handshake simulation.

3. Added TCP sequence numbers and acknowledgement numbers.

4. Added TCP window size and TCP flags.

5. Added TCP data length information.

6. Added flow-control and congestion-control simulation.

7. Added TCP connection teardown using FIN and ACK messages.

8. Added Transport Layer flows for Browsing, Mail and Streaming.

9. Assisted with debugging when the Send Email function stopped working.

10. Assisted with improving the dashboard interface while keeping the original Assignment 1 layout and functionality.

11. Assisted with preparing the README, reflection document and project documentation.
